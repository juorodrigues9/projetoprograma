# Visualização da plataforma (MVP)

Para facilitar sua validação, foi criado um protótipo visual navegável em:

- `prototipo/index.html`

## O que você consegue visualizar

1. **Painel com os 31 quartos** e status em cores.
2. **Resumo diário** (ocupação e recebimentos).
3. **Fluxo de checkout** com total da conta e botões de pagamento.
4. **Fila de limpeza** após checkout com ação para liberar quarto.

## Como abrir localmente

```bash
python -m http.server 4173
```

Depois acesse:

- `http://localhost:4173/prototipo/index.html`

## Observação

Este protótipo é somente visual (sem backend real ainda), para aprovar layout e fluxo operacional antes da implementação completa.
